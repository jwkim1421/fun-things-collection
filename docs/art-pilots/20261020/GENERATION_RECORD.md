도구에는 각 화풍의 프로젝트 기준 PNG를 파일 경로로 전달했습니다. 아래의 `cover.png`는 해당 입력과 같은 바이트로 복사한 전달용 참조입니다. 역할은 화풍과 인물 외형이며, 결과마다 새 행동·장면을 요청했습니다. 원본 수령 후에는 파일 복사만 했고 별도 크롭·색 보정은 하지 않았습니다. 모델 ID·seed·요금은 제공되지 않아 기록하지 않았습니다.
