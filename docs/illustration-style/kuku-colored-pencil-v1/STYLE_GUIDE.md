# 그림체 가이드 S3 · 색연필로 관찰한 생활 장면

작성: 2026-10-20 · 기준 ID: `kuku-colored-pencil-v1` · 상태: **기준 후보, 사이트 미적용**

## 1. 다른 작업자에게 전달할 자료

이 `STYLE_GUIDE.md`와 같은 폴더의 `reference.png`를 실제 파일로 함께 첨부합니다. 그림을 보지 않은 채 링크나 텍스트만으로 그림체를 확인했다고 쓰지 않습니다. 두 파일은 폴더째 옮겨도 서로 연결됩니다.

![동갈색 곱슬머리 인물이 작은 전시 공간 문을 잡고 나무와 벤치가 있는 골목을 바라보는 색연필 그림](reference.png)

이 그림은 **선·겹쳐 칠한 결·종이·공간 묘사**의 참조입니다. 문·골목·초록 재킷을 모든 새 콘텐츠에 복제하는 규칙이 아닙니다. 특정 테스트의 후속 그림이라면 인물 외형·의상·소지품을 별도 기준으로 함께 유지합니다.

## 2. 그림에서 확인한 특징과 유지할 규칙

**한 문장:** 가는 윤곽과 방향이 보이는 색연필 층으로, 인물의 구체적인 행동과 머물 공간을 함께 그린 생활화.

| 요소 | 기준 그림에서 보이는 특징 | 후속 제작 규칙 |
|---|---|---|
| 선 | 얼굴·손·공간을 잡는 가는 윤곽, 부분적으로 색 속에 섞인 경계 | 주요 형태는 분명하게 하되 모든 사물에 굵은 검은 선을 두르지 않음 |
| 채색 | 재킷·바지·벽에 겹쳐 칠한 사선과 짧은 선, 종이가 비치는 틈 | 결의 방향으로 재료와 형태를 그림. 완성 그림 위에 같은 노이즈만 덮지 않음 |
| 색 | 초록 재킷·주황 벽·파란 하늘·자두색 수첩이 구별됨 | 선명한 색도 사용. 모두 흐린 베이지나 파스텔로 제한하지 않음 |
| 명암 | 연필 층과 구분되는 빛·그림자 면, 바닥의 나뭇잎 그림자 | 밝기를 연필 선과 색의 층으로 만듦. 배경의 매끈한 디지털 그라데이션·발광은 금지 |
| 인물 | 펜 만화보다 현실에 가까운 비율, 옆을 보는 얼굴과 문을 잡은 손 | 인물 비율과 손의 접촉을 자연스럽게. 사진 위 필터나 큰 눈의 만화로 대체하지 않음 |
| 공간 | 문턱·창·골목이 이어지고 나무·벤치가 바닥에 놓임 | 하나의 연결된 장소를 구성. 풍경 조각·사진·문구를 띄워 붙이지 않음 |
| 밀도 | 골목과 실내의 세부 묘사가 비교적 많음 | 이는 원본의 특성이며 필수 소품 수가 아님. 작은 카드용 장면은 배경을 줄일 수 있음 |

화풍을 ‘차분함’ 하나로 고정하지 않습니다. 활기 있는 전시·밤의 발견도 같은 연필 재료로 그립니다. 다만 조명 효과를 넣기 위해 발광이나 그라데이션 배경을 사용하는 것은 허용하지 않습니다.

## 3. 고정할 것과 바꿀 것

| 화풍에서 고정 | 새 콘텐츠에 맞게 변경 |
|---|---|
| 가는 윤곽, 겹친 연필 결, 보이는 종이 틈 | 인물·의상·장소·주조색·시간대 |
| 공간 안에서 읽히는 행동과 접촉 | 작업·선택·기록·걷기 등 주제의 행동 |
| 배경 그라데이션·문자·아이콘 콜라주 제외 | 시점·인물 수·물체 수·공간 밀도 |

‘오늘 끌리는 장면’의 대표 제작에서는 짧은 동갈색 곱슬머리·초록 재킷·자두색 수첩의 인물을 후보로 유지합니다. 이 인물이나 유럽풍으로 보이는 골목이 사이트 전체의 필수 설정은 아닙니다. 다른 테스트의 지역·장소는 해당 내용에 맞게 바꿉니다.

## 4. 복사해서 사용할 요청문

대괄호를 채우고 `reference.png`를 첨부합니다. 특정 인물 기준을 추가할 때는 그림체 참조와 인물 외형 참조의 역할을 따로 명시합니다.

```text
첨부한 reference.png는 가는 선·겹친 색연필 결·종이 틈·공간 묘사의 그림체 참조입니다.
원본의 문·골목·인물을 복제하지 말고 다음 한 장면을 그려 주세요.
장면: [누가 / 어디에서 / 어떤 행동을 하며 / 무엇을 느끼는가]
인물 외형: [새 인물 설명 또는 함께 첨부한 인물 기준의 유지 항목]
핵심 동작과 공간 관계: [어디를 보고 무엇에 닿아 있는가]
용도와 비율: [표지/결과, 필요한 가로세로 비율]
가는 흑연·색연필 윤곽과 방향이 보이는 짧은 선, 겹쳐 칠한 색과 비치는 종이 틈을 유지하세요.
색은 주제에 맞게 선명하게 써도 됩니다. 전체를 흐린 베이지로 만들지 마세요.
주인공의 얼굴·핵심 동작을 읽을 수 있게 구성하고 필요한 공간·소품만 남기세요.
배경 그라데이션·에어브러시·발광·굵은 만화 외곽선·물감 덩어리·사진 필터는 제외하세요.
그림 안에는 글자·숫자·로고·워터마크·말풍선·떠다니는 기호·사진 콜라주를 넣지 마세요.
```

## 5. 제작할 때 확인할 것

1. 옷·벽·하늘에서 연필 결의 방향과 종이 틈이 보이는지 확인합니다.
2. 같은 재료로 밝은 장면과 활기 있는 장면이 가능한지 봅니다. 색만 흐리게 해서 통일하지 않습니다.
3. 얼굴·손·문턱·물건의 접촉이 자연스러운지 확인합니다.
4. 복잡한 나무·골목·실내 소품이 주인공보다 앞서면 배경부터 줄입니다.
5. 실제 카드·공유 이미지의 판독과 잘림은 후속 화면 단계에서 확인합니다.

이번에는 한 장면의 원본을 육안으로 확인했습니다. 다른 장면에서의 인물·화풍 일관성과 실제 화면 적합성을 검증한 것은 아닙니다.

Use case: illustration-story.

A sky is one even blue pencil-colored area with paper grain, wall is one local terracotta/cream color area; material pencil variation is short directional strokes rather than broad smooth blends.

No letters, numbers, logos, captions, watermark, speech bubbles, floating hearts/stars, UI, sticker icons or borders. No separate swatches or sample panels.
