사용자는 두 번째·세 번째 수정에서 지나치게 선명해지고 입체감이 줄었다고 판단했습니다. 현재 `reference.png`는 최초 출력과 같은 원본입니다. 아래의 현재 제작 규칙은 첫 그림의 펜선·부드러운 명암·공간감을 따릅니다. 과거의 평면화 수정 요청은 이력으로만 남기며 다시 적용하지 않습니다.

참조는 **선·부드러운 채색·입체감·표정의 기준**입니다. 이 여자 캐릭터는 사용자가 쿠쿠와 함께 사용할 마스코트로 지정했습니다. 마스코트 장면에서는 같은 얼굴·머리·기본 의상을 유지하고, 다른 인물이 필요한 테스트에서는 그 외형을 별도로 정합니다. 방·과자·책상을 공통 소품으로 복제하지 않습니다.

## 2. 그림에서 확인한 특징과 유지할 규칙

**한 문장:** 굵기가 달라지는 펜선과 부드러운 형태 명암으로, 표정·손동작과 공간의 깊이가 함께 읽히는 생활 만화.

| 요소 | 기준 그림에서 보이는 특징 | 후속 제작 규칙 |
|---|---|---|
| 외곽선 | 검정에 가까운 외곽선과 가는 내부선, 머리카락과 옷의 세부 선 | 첫 그림의 선 굵기를 유지. 얼굴·손을 과하게 굵은 선으로 재단순화하지 않음 |
| 단순화 | 큰 눈, 작은 입, 단순한 코, 과자를 향한 눈과 손 | 얼굴과 손의 행동을 먼저 읽게 함. 모든 인물에 같은 얼굴을 붙이지 않음 |
| 채색 | 파랑 옷·코랄 포장·노랑 탁자와 피부·주름의 미묘한 밝기 차이 | 주제에 맞게 색을 바꾸되 첫 그림의 부드러운 모델링과 볼륨을 유지 |
| 명암 | 볼·머리·니트 주름·가구에 형태와 겹침을 보여주는 명암 | 인물과 물체의 입체감을 제거하지 않음. 배경의 장식용 디지털 그라데이션·후광은 추가하지 않음 |
| 공간 | 의자·노트·과자가 같은 책상 주변에 연결됨 | 인물과 물건이 실제로 닿고 놓인 공간. 아이콘을 띄우거나 스티커처럼 배열하지 않음 |
| 표정·동작 | 글 쓰던 손과 과자를 집는 손, 옆으로 향한 시선 | 유머는 구체적인 행동에서 만듦. 말풍선 문장·장식 기호로 대신하지 않음 |
| 밀도 | 침대·책장·식물·탁자가 생활 공간을 연결하고 인물이 중심에 있음 | 생활 공간의 깊이를 유지하고 필요 없는 소품만 줄임. 배경을 무조건 평평한 벽으로 바꾸지 않음 |

색 이름은 원본의 관찰값입니다. 코발트색 니트는 등록한 여자 마스코트의 현재 기본 의상이며 모든 새 인물의 공통 의상은 아닙니다. 배경 그라데이션 금지를 이유로 인물의 명암까지 평면화하지 않습니다. 첫 원본은 재보정 없이 보존합니다.

## 3. 고정할 것과 바꿀 것

| 화풍에서 고정 | 새 콘텐츠에 맞게 변경 |
|---|---|
| 첫 그림의 펜선, 부드러운 형태 명암, 공간의 깊이 | 다른 인물이 필요한 경우 그 외형·의상·주조색 |
| 한 컷 안의 분명한 행동과 시선 | 장소·소품·시간·카메라 방향 |
| 배경 그라데이션·문자·아이콘 콜라주 제외 | 주제에 필요한 구체적 상황 |

‘미루기 빙고’에서는 검은 단발·코발트 니트의 같은 여자 마스코트를 유지합니다. 기존 쿠쿠와 함께 사용할 캐릭터로 등록했지만 모든 테스트에 의무 출연시키지는 않습니다. 이름·나이·보이지 않은 전신 규격·쿠쿠와의 서사는 아직 미정입니다.

## 5. 제작할 때 확인할 것

1. 표정·시선·두 손에서 설명 없이도 행동이 읽히는지 봅니다.
2. 첫 그림의 선·명암·공간감이 남았는지 봅니다. 다시 과도한 굵은 선과 평평한 색 면으로 바뀌면 수정합니다.
3. 손가락·연필·포장·탁자의 접촉을 확인합니다. 형태 오류를 손맛으로 넘기지 않습니다.
4. 얼굴·핵심 동작의 잘림, 배경 그라데이션, 글자 찌꺼기가 없는지 확인합니다.
5. 실제 카드·공유 이미지 판독은 후속 단계에서 확인합니다. 이번 원본 육안 검토를 실기기 검사로 부르지 않습니다.

4단계에서는 이 첫 원본을 참조해 같은 여자 마스코트의 착수·막판 몰입 결과를 제작했습니다. 실제 카드·공유 화면 검토와 추가 포즈의 재현은 별도 후속 작업입니다.
