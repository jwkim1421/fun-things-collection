# 그림체 가이드 S4 · 펠트 인형의 미니어처 세계

작성: 2026-10-20 · 기준 ID: `kuku-felt-miniature-v1` · 상태: **기준 후보, 사이트 미적용**

## 1. 다른 작업자에게 전달할 자료

이 `STYLE_GUIDE.md`와 같은 폴더의 `reference.png`를 실제 파일로 함께 첨부합니다. 두 파일은 폴더째 옮겨도 서로 연결됩니다. 그림을 보지 않은 채 파일명이나 링크만으로 그림체를 확인했다고 쓰지 않습니다.

![펠트 고양이가 작은 방에서 청록색 쿠션을 들고 노란 의자 옆에 서 있는 미니어처 장면](reference.png)

참조의 역할은 **펠트·천·봉제·인형 비율·세트의 연결**입니다. 실제 수공예품을 촬영했다는 제작 이력이 아닙니다. 고양이·침대·의자·쿠션을 모든 콘텐츠에 그대로 넣는 규칙도 아닙니다.

## 2. 그림에서 확인한 특징과 유지할 규칙

**한 문장:** 짧은 섬유와 봉제선이 보이는 둥근 인형이 작은 세트 안에서 직접 물건을 만지는, 손으로 만든 듯한 장면.

| 요소 | 기준 그림에서 보이는 특징 | 후속 제작 규칙 |
|---|---|---|
| 인형 재료 | 몸·귀·얼굴의 양모 같은 섬유, 조금 불규칙한 표면 | 매끈한 플라스틱이나 털 필터로 바꾸지 않음. 얼굴을 가릴 만큼 긴 털은 피함 |
| 눈·얼굴 | 수정 후 빛 반사가 없는 작은 검은 자수 눈, 작은 코·입 | 유리구슬 하이라이트를 넣지 않음. 작아도 시선과 얼굴 방향이 읽히게 함 |
| 봉제 | 쿠션 테두리·조끼·의자 등에 실과 겹친 재료 경계 | 접합부에 필요한 봉제를 표현. 모든 표면에 같은 점선 장식을 뿌리지 않음 |
| 비율·행동 | 큰 머리·짧은 팔·둥근 발, 두 앞발로 쿠션을 잡음 | 중요한 동작을 몸과 시선으로 읽히게 함. 팔다리가 소품과 합쳐지지 않게 함 |
| 공간 | 발·의자·선반이 같은 바닥과 벽에 연결됨 | 빈 단상이나 떠다니는 소품 배열 대신 하나의 방·부스·탁자 안에 구성 |
| 색·깊이 | 세이지 벽·주황 바닥·청록 쿠션·노랑 의자, 접촉 그림자와 겹침 | 배경은 한 재료의 고유색. 깊이는 형태·재료·접촉 그림자로 표현하고 디지털 배경 그라데이션은 넣지 않음 |
| 밀도 | 원본에는 창·침대·선반·바구니도 있음 | 모두 필수 소품이 아님. 주제와 인물 동작을 먼저 두고 필요 없는 물건은 제외 |

배경에 물체·광원과 무관한 색 번짐·후광·비네트를 추가하지 않습니다. 인형과 세트의 입체적 그림자는 유지할 수 있습니다. 이는 배경 그라데이션을 허용하는 예외가 아닙니다.

## 3. 고정할 것과 바꿀 것

| 화풍에서 고정 | 새 콘텐츠에 맞게 변경 |
|---|---|
| 섬유 결·봉제·천의 가장자리·무광 자수 눈 | 인물의 종·몸색·의상·사용 재료색 |
| 단순한 인형 비율과 분명한 몸짓 | 방·축제·놀이 탁자 등 세트와 행동 |
| 물체의 접촉·바닥·겹침 | 시점·인물 수·소품 수·장소 규모 |
| 그라데이션 배경·글자·아이콘 콜라주 제외 | 주제에 필요한 색과 장면의 밀도 |

‘내 방 취향’의 대표 제작에서는 크림 몸·회색 귀·작은 자수 눈·녹슨 주황색 조끼의 고양이를 후보로 유지합니다. 방 구조는 비교를 위해 이어 쓸 수 있지만 모든 결과에 같은 소품을 남기지는 않습니다. 이 고양이는 쿠쿠의 새 외형으로 확정한 캐릭터가 아닙니다.

쿠쿠가 필요한 장면에서는 **별도의 쿠쿠 외형 기준을 추가 첨부**합니다. 이 파일은 재료 표현, 별도 캐릭터 이미지는 얼굴·색·비율의 기준이라고 역할을 나눕니다. 해당 외형 기준은 이 두 파일 묶음에 포함되지 않습니다.

원본 고양이·방·쿠션을 자동으로 복제하지 말고 다음 한 장면을 만들어 주세요.

## 5. 제작할 때 확인할 것

1. 인물·쿠션·가구의 재료가 구별되고 필요한 섬유·봉제가 보이는지 확인합니다.
2. 눈이 매끈한 구슬로 돌아가지 않았는지, 표정이 털에 묻히지 않는지 봅니다.
3. 두 발의 접지와 앞발·소품의 접촉을 확인합니다. 인형·쿠션이 한 덩어리로 합쳐지면 수정합니다.
4. 재료감만 보여주는 상품 컷이 되면 시선·동작·상황을 먼저 수정합니다.
5. 실제 카드에서 행동과 재료가 함께 읽히는지, 다른 결과에서도 같은 외형을 유지하는지는 다음 단계에 남아 있습니다.

이번 방 시안은 재료 후보를 보여 줍니다. 쿠쿠 외형 재현·축제 장면의 연속성·작은 화면 판독까지 통과한 것으로 해석하지 않습니다.
