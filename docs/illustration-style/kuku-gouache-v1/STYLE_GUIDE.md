# 쿠쿠 그림체 가이드 v1: 따뜻한 과슈 생활 장면

작성: 2026-10-20 · 기준 ID: `kuku-gouache-v1`

**목표:** 아래 그림의 선·채색·질감·표정·분위기를 다른 AI나 작업자가 이어서 사용할 수 있도록 기록합니다. ‘소셜 배터리’라는 내용과 거실 구도를 그대로 복제하는 지침은 아닙니다. 사용자가 이 그림을 향후 재사용할 그림체 참조로 남겨 달라고 요청해 작성했습니다. 사이트 전체 적용이나 캐릭터 전체 규격 확정은 별도입니다.

## 1. 다른 AI에게 전달할 두 파일

이 문서 **`STYLE_GUIDE.md`와 같은 폴더의 `reference.png`를 함께 첨부**합니다. Markdown 안 이미지 링크만 전달하면 다른 AI가 원본을 보지 못할 수 있으므로 PNG도 실제 첨부합니다. 두 파일은 폴더째 옮겨도 서로 연결됩니다.

![쿠쿠 그림체 기준 이미지. 붓질이 보이는 따뜻한 거실에서 대화하는 시바견·토끼와 쉬는 강아지](reference.png)

**참조 이미지의 역할은 그림체 기준입니다.** 원본 장면을 수정할 때에만 편집 대상 역할도 부여합니다. 새 테스트를 그릴 때는 아래 ‘주제 변경용 요청문’의 장면 부분만 바꿉니다.

| 필요한 자료 | 역할 | 사용 방법 |
|---|---|---|
| 이 문서 | 표현 규칙·요청문·검토 기준 | 새 요청과 함께 전달 |
| `reference.png` | 선·색 면·붓질·표정·밀도의 시각 기준 | **필수 첨부** |
| 별도 캐릭터 기준 그림 | 특정 캐릭터의 외형 | 쿠쿠 얼굴까지 동일하게 유지해야 할 때 추가. 아래 구분 참고 |

**빠른 전달문:**

```text
첨부한 STYLE_GUIDE.md를 읽고 reference.png를 실제로 확인해 주세요.
reference.png는 그림체 참조입니다. 같은 선·채색·붓질·표정의 표현을 유지하면서 다음 장면을 새로 그려 주세요.
새 장면: [누가 / 어디에서 / 무엇을 하며 / 어떤 감정을 보이는지]
기준 이미지의 거실·소파·세 동물을 새 장면에 그대로 넣을 필요는 없습니다.
그라데이션 배경, 글자, 아이콘 콜라주는 사용하지 마세요.
```

## 2. 그림체를 한 문장으로 정의하면

**따뜻한 생활 공간에서 둥글고 표정이 풍부한 캐릭터가 행동하는, 짙은 갈색 잉크 선과 불투명한 과슈·마른 붓 질감의 장면형 일러스트.**

여기서 ‘과슈’는 불투명한 물감으로 칠한 듯한 **보이는 표현**을 뜻합니다. 실제 종이에 물감으로 그렸다는 제작 이력은 아닙니다. 아래 규칙은 참조 이미지의 육안 관찰과 후속 제작 지침입니다.

## 3. 꼭 유지할 시각적 특징

| 요소 | 기준 이미지에서 보이는 특징 | 다음 그림에 요구할 내용 |
|---|---|---|
| 외곽선 | 캐릭터에는 검정에 가까운 짙은 갈색 선이 굵고 또렷함. 배경은 붓질·색 경계가 중심 | 손으로 그은 듯한 불규칙한 선. 캐릭터 외곽을 가장 강하게 하고, 배경 가구·식물까지 모두 같은 굵기로 두르지 않음 |
| 선과 색의 관계 | 물감 가장자리가 선에 딱 맞지 않는 부분, 부분적으로 끊기는 경계 | 모든 테두리를 균일하게 닫거나 색을 완벽하게 맞추지 않음 |
| 채색 | 불투명한 색 면 위에 더 밝거나 어두운 짧은 붓질 | 큰 색 덩어리를 먼저 읽게 하고, 작은 붓 자국으로 재료 느낌을 추가 |
| 질감 | 벽·소파·옷·털·나무에 종이 결과 마른 붓 흔적 | 표면마다 결 방향을 다르게. 전체에 같은 노이즈 필터를 덮는 것으로 대체하지 않음 |
| 명암 | 평면적인 밝고 어두운 면, 겹치는 물감 자국 | 단순한 색 면으로 입체감을 만들고 부드러운 디지털 그라데이션 배경은 금지 |
| 색의 인상 | 노란 벽·주황 털·붉은 소파가 중심, 녹색·파랑이 보조 | 따뜻한 주조색에 차가운 보조색을 소량 사용. 모두 흐린 파스텔로 만들지 않음 |
| 캐릭터 형태 | 둥근 몸, 큰 머리·귀, 단순한 눈·코·입, 볼의 붉은 기 | 작게 보여도 감정이 읽히는 얼굴과 자연스러운 몸짓 |
| 감정 표현 | 말하는 입·앞발 동작, 상대를 보는 시선, 편하게 감은 눈 | 표정·시선·자세가 함께 감정을 전달하도록 그림 |
| 공간 | 인물·소파·탁자가 겹치며 한 공간에 놓임 | 하나의 연결된 장면. 사물과 캐릭터를 따로 잘라 붙인 배열은 피함 |
| 완성도 | 의도적으로 거친 붓질이 있지만 주요 형태는 분명함 | 어긋난 해부·녹아내린 손발·정체불명 소품을 ‘손맛’으로 넘기지 않음 |

## 4. 유지할 그림체와 바꿔도 되는 내용을 구분

| 고정할 것 | 주제에 맞게 바꿀 것 |
|---|---|
| 불규칙한 짙은 갈색 선, 불투명한 물감 면, 마른 붓·종이 질감 | 장소·시간대·가구·소품·카메라 방향 |
| 따뜻하고 생기 있는 색, 단순한 색 면 명암 | 주제별 강조색·보조색의 조합 |
| 둥근 캐릭터와 잘 읽히는 표정·행동 | 동물·사람·주인공 수와 역할 |
| 한 공간 안에서 자연스럽게 연결되는 장면 | 대화·망설임·공부·휴식 등 행동과 상황 |
| 그라데이션 배경 금지, 그림 속 글자 없음 | 가로·세로 비율과 홍보 문구의 외부 편집 |

**참조의 시바견과 기존 쿠쿠 마스코트는 동일 캐릭터로 확정되지 않았습니다.** 이번 원본은 기존 얼굴을 참조 이미지로 넣지 않고 생성했습니다. 시바견의 초록 스카프, 토끼의 파란 옷, 오른쪽 강아지는 이 장면의 요소이며 브랜드 공통 의상·캐릭터 규칙이 아닙니다.

쿠쿠 얼굴까지 유지하려면 다음과 같이 역할을 나눕니다.

```text
이미지 1: reference.png. 선·채색·질감·분위기만 참고합니다.
이미지 2: 별도로 첨부한 쿠쿠 캐릭터 기준. 얼굴의 털 색, 크림색 볼, 귀 모양, 눈·코·입과 비율을 유지합니다.
캐릭터의 외형은 이미지 2를 우선하고, 표현 재료와 그림체는 이미지 1을 따릅니다.
새 장면에 맞게 자세와 행동을 바꾸세요. 참조 이미지 1의 스카프나 동료 동물을 자동으로 추가하지 마세요.
```

현재 프로젝트의 별도 얼굴 기준은 `assets/images/kuku-mascot-full.png`입니다. 이 두 파일 묶음에는 포함하지 않았습니다. 캐릭터 동일성까지 필요한 작업에서는 해당 PNG를 추가로 전달해야 합니다. 몸 전체 규격은 아직 확정되지 않았습니다.

## 5. 구도와 화면 사용 기준

원본은 **1536×1024px, 가로 3:2**입니다. 조금 위에서 보는 실내 장면으로 탁자와 소파가 캐릭터들을 연결합니다. 캐릭터가 그림에서 충분히 크게 보이고 귀·얼굴이 프레임 안에 들어옵니다. 다음 그림도 같은 방식으로 주제를 읽을 수 있게 구성합니다.

- 주요 행동과 표정을 먼저 정하고 그에 필요한 장소·소품을 배치합니다.
- 인물·가구의 겹침으로 깊이를 만들되 서로 몸이 합쳐지지 않게 합니다.
- 주요 얼굴·귀·손발의 동작은 잘리지 않도록 둡니다. 배경 물체의 자연스러운 프레임 밖 잘림은 가능합니다.
- 불필요한 빈 테두리·넓은 단색 여백을 추가하지 않습니다. 얼굴을 보호하는 여유와 장식용 여백은 구분합니다.
- 이 원본에는 배경 소품이 많습니다. **그림체 보존에 소품 수까지 똑같이 맞출 필요는 없습니다.** 작은 테스트 카드에서는 소품을 줄이고 주인공·표정을 키울 수 있습니다.
- 제목은 그림 바깥의 텍스트로 배치합니다. 생성 이미지 안에는 글자·가짜 글자·말풍선 문장을 넣지 않습니다.
- 세로 홍보물이 필요하면 처음부터 세로 구도로 다시 구성합니다. 가로 그림을 자르기만 해서 캐릭터를 잘라내지 않습니다.

## 6. 주제 변경용 요청문

### 한국어 버전

아래 요청에서 대괄호 부분을 채우고 `reference.png`를 함께 첨부합니다. 선택 항목은 필요 없으면 줄 전체를 삭제합니다.

```text
목적: 쿠쿠 테스트의 주제별 장면형 표지 일러스트.
스타일 참조: 첨부한 reference.png. 이 이미지를 실제로 보고 선·채색·붓질·표정의 표현을 맞춰 주세요.

새 장면: [누가, 어디에서, 어떤 행동을 하며 어떤 감정을 보이는지 구체적인 한 장면]
핵심 감정: [예: 답장을 보내기 전의 설렘과 머뭇거림]
주요 인물: [필요한 인물과 역할. 필요하지 않은 참조 동물은 추가하지 않음]
장면에 필요한 소품: [주제 전달에 필요한 것만]
비율과 용도: [기본 가로 3:2 / 세로 포스터 등]
선택: [별도 첨부 캐릭터 기준이 있으면 파일명과 반드시 유지할 외형]

그림체: 따뜻하고 생기 있는 생활 장면. 손으로 그은 듯 조금 흔들리고 굵기가 달라지는 짙은 갈색 잉크 선. 캐릭터 외곽선은 가장 강하게, 배경 가구·식물은 붓질과 색 경계를 중심으로 표현. 불투명한 과슈 색 면에 마른 붓 흔적과 종이 결이 보이게. 재료마다 결 방향을 다르게 하고 주요 형태와 얼굴은 명확하게.
채색: 따뜻한 주조색에 녹색·바랜 파랑 계열을 보조로 사용. 단순한 밝고 어두운 색 면과 겹친 붓질로 입체감을 표현.
캐릭터: 둥근 형태, 표현력 있는 눈·입·시선·몸짓. 한 공간 안에서 자연스럽게 행동하고 상호작용하게.
구도: 주요 행동과 표정이 작은 카드에서도 읽히게. 인물·장소·소품이 하나의 장면으로 연결되게. 얼굴과 귀, 핵심 동작은 프레임 안에 보존.

제외: 그라데이션 배경, 부드러운 디지털 에어브러시·발광, 매끈한 3D, 균일한 벡터 선, 기업용 클립아트, 아이콘·스티커 콜라주, 떠다니는 하트·별, 그림 속 글자·숫자·로고·워터마크, 의미 없는 소품 채우기.
원본의 거실·붉은 소파·세 동물 배치를 복제하지 말고 새 장면에 필요한 내용만 그려 주세요.
```

### English version

```text
Create an original narrative illustration for a Kuku personality-test cover.
Use the attached reference.png as the visual style reference. Preserve its line quality, opaque painted color blocks, dry-brush texture, expressive faces, and warm lively mood.

New scene: [who is doing what, where, and how they feel; one specific scene].
Main emotional beat: [emotion].
Characters and roles: [only the characters needed for this scene].
Necessary props: [only props that communicate the topic].
Aspect ratio and use: [landscape 3:2 by default, or the requested format].
Optional character reference: [identify any additional identity reference and the appearance that must remain fixed].

Style: hand-painted picture-book and everyday-life illustration. Slightly wobbly, variable-weight dark-brown ink contours; opaque gouache paint with visible broken dry-brush marks and subtle paper grain. Give the main characters the strongest contours; describe background furniture and plants mainly through brushwork and color boundaries instead of outlining everything with the same heavy line. Let edges feel hand-painted while keeping faces and key forms clearly readable. Vary texture direction with the material.
Color and shading: warm, lively dominant colors with restrained olive and faded-blue accents. Build volume with discrete painted light and dark shapes and overlapping brush marks.
Characters: rounded forms with expressive eyes, mouths, gazes, and gestures. Show believable action and interaction within one coherent environment.
Composition: make the main action and emotions readable at thumbnail size. Connect characters, furniture, and props spatially. Keep complete faces, ears, and the important gesture inside the frame.

Exclude gradient backgrounds, smooth airbrush shading, glow, glossy 3D, uniform vector outlines, corporate clip art, isolated icon or sticker collages, floating hearts or stars, lettering, numbers, logos, watermarks, and purposeless decorative clutter.
Transfer the visual style, not the original living room, red sofa, or three-animal arrangement. Draw the new scene with only the subjects it requires.
```
